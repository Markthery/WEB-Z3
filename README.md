# Спасение кота — платформер на JavaScript

Браузерная игра на Canvas без движков, npm и сборки. Кот заперт в клетке на крыше. Нужно собрать три ключа, обойти шипы и добежать до клетки.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Влево / вправо | ← → или A D | кнопки ◀ ▶ (можно удерживать) |
| Прыжок | Space, W или ↑ | кнопка «Прыжок» |

Прыжок в воздухе запрещён. Кнопки на странице: «Старт», «Пауза» / «Продолжить», «Заново».

## Правила

- Ключи по 100 очков. После победы добавляется бонус за скорость.
- Победа: все три ключа собраны и герой дошёл до клетки.
- Поражение: падение с крыши или касание шипов.
- Рекорд хранится в `localStorage` и сохраняется после обновления страницы.
- При уходе со вкладки игра ставится на паузу.

## Запуск

ES-модули не работают при открытии `index.html` двойным кликом (`file://`), нужен любой статический сервер:

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

## Структура

- `index.html`, `style.css` — страница, HUD, кнопки и экранное управление.
- `main.js` — точка входа.
- `Game.js` — уровень, состояния, один игровой цикл `requestAnimationFrame`, рекорд, рисование.
- `Player.js` — движение, прыжок, гравитация (скорости в px/s, обновление принимает `dt`).
- `input.js` — клавиатура и экранные кнопки, очистка клавиш при паузе.
- `collision.js` — столкновения сверху, сбоку и снизу с учётом прежнего положения.

Код создан с помощью Claude (Anthropic) по шагам из задания. Тема — «спасение кота», стиль — ночные крыши. Примеры промптов:

2. «Добавь Player: движение стрелками или A/D, прыжок Space/W, гравитацию. Скорость в пикселях в секунду, обновление принимает dt. Прыжок только с опоры.»
3. «Добавь один проходимый уровень с пятью платформами. Реализуй столкновения сверху, сбоку и снизу.»
4. «Собери игровой цикл через requestAnimationFrame: update(dt), затем render(). При паузе очищай клавиши и сбрасывай время кадра.»
5. «Добавь три предмета, счёт, опасную зону и финиш. Победа — после всех предметов и финиша.»
6. «Добавь старт, паузу, продолжить, заново. Рекорд сохраняй в localStorage с обработкой ошибок.»
7. «Улучши графику в теме спасения кота и добавь экранные кнопки для телефона с удержанием.»

## Ресурсы

Картинки и звук не используются: вся графика нарисована фигурами Canvas.

## Что проверить перед сдачей

- Пройти уровень от старта до победы.
- Проверить поражение от падения и от шипов.
- Проверить паузу, смену вкладки и пять рестартов подряд: скорость игры не должна расти.
- Проверить края платформ и экранные кнопки на телефоне.
- Проверить рекорд после обновления страницы.
